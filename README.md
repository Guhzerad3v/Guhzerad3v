## 🤖 Como uso IA e Prompts Técnicos no meu fluxo de trabalho

Minha forma de trabalhar é **human‑centric, mas amplificada por IA**:

- **Arquitetura de prompts**:  
  - Uso **templates de prompts técnicos** para design de APIs, documentação de sistema, planejamento de releases e revisão de código.  
  - Crio **meta‑prompts** para que o modelo:

    - pense em arquitetura (separação de responsabilidades, componentes, fluxo de dados).  
    - liste trade‑offs (performance × custo, simplicidade × escalabilidade).  
    - sugira testes e corner‑cases.  

- **Agente de memória técnica**:  
  - Uso **Obsidian** como hub de conhecimento pessoal, integrando links para repositórios, docs e decisões de arquitetura.  
  - Daí rodo buscas contextuais com IA para **recuperar decisões passadas, padrões de código e lições aprendidas**.

- **Automação de rotina**:  
  - Uso **Ollama local** + **scripts Python** para:
    - gerar documentação inicial de APIs.  
    - resumir issues antigas antes de começar um novo ciclo.  
    - ajudar na criação de release notes e changelogs.  
  - Isso me permite focar em **design de sistema, gestão de produto e interação humano‑a‑humano**, não em tarefas repetitivas.

- **Custo × qualidade**:  
  - Orquestro entre **Antropic, Groq, Ollama e Voyage AI** dependendo do tipo de trabalho:
    - Análise de código e arquitetura → modelos mais robustos.  
    - Busca rápida e resumos → modelos locais rápidos.  
   - Uso **Tavily Search** sempre que preciso de contexto externo (benchmarking, documentação, referências de mercado(Quando Low-Cost) ).
